🔗 Collection Relationships

users ↔ jobs: jobs.ownerId & jobs.providerId reference users.uid
jobs → statusUpdates: statusUpdates subcollection under each job
jobs → gpsTracking: gpsTracking subcollection under each job
users ↔ notifications: notifications.userId references users.uid
jobs ↔ notifications: notifications.jobId references jobs.jobId
users/jobs → adminLogs: adminLogs.targetId can reference users.uid or jobs.jobId

🔒 Security Rules Summary

Users Collection: Users can only read/write their own documents
Jobs Collection: Only job owner and assigned provider can access
Status Updates: Inherited from parent job permissions
GPS Tracking: Inherited from parent job permissions
Notifications: Users can only see their own notifications
Admin Logs: Only admin role can access
